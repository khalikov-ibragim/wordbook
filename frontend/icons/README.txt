icon-192.png и icon-512.png сгенерированы автоматически (простой WB-значок
в цветах темы: оранжевый фон FF7A3D + кремовая карточка FFF9F0) — этого
достаточно, чтобы установка PWA на телефон/ПК показывала иконку, а не
заглушку. Если захочешь свой логотип — просто замени эти два файла
(квадратные, без прозрачных полей по краям — их иногда обрезают на
Android/iOS).

Быстрый вариант для кастомного лого: сгенерировать из одного PNG на
https://realfavicongenerator.net/ или через
`npx pwa-asset-generator логотип.png ./icons`.
